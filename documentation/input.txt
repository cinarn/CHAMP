BFF density: main shells and cached exact angular sub-rings
---------------------------------------------------------
conf_bff       Main radial shell populations, ordered inside out; sum=nelec.
sub_conf_bff   Full consecutive sub-ring population list; sum=nelec.
               Each main shell is unsplit or contains equal-M sub-rings.
               If omitted, defaults to conf_bff.
sub_id_bff     Selected index in sub_conf_bff; zero disables BFF density.

Example: conf_bff=2 8, sub_conf_bff=2 2 2 2 2, sub_id_bff=5.
Counts and M_bff are derived internally. Remove old ring_id_bff and nrings_bff
namelist entries. Lists and workspaces are sized from nelec, without a 20-entry
limit. Active BFF requires nonperiodic 2D, icoosys=1 and ifixe=-2, -3 or -4.

After main-shell radial sorting, the innermost unused electron anchors a group.
Distinct partners maximize the sum of cosine scores to its regular M-polygon
slots through exact rectangular assignment. Groups are ranked by mean radius.
This optimizes partners per anchor, not the joint partition of the whole shell.
Single-electron, single-slot and forced final-group memberships use exact fast
paths. Unsplit shells retain the base radial ordering and angle calculation.

Fixed target-slot sine/cosine values and assignment storage are prepared once.
For every configuration, unit vectors and each anchored group's score matrix
are recomputed; no coordinate-dependent score survives an electron move.
Slot rows are ordered canonically by score vectors for slot-order-independent
tie handling. Exact geometric/radial degeneracies need not define unique rings.

Shell order parameters and inter-ring correlation always use MAIN conf_bff.
The correlation uses its two outermost main shells and their lcm harmonic.
Lab-frame origin, p/q weights, spin labels and normalization are unchanged.

Collective VMC/DMC rotations (opt_list)
--------------------------------------
irot_every=0 disables collective rotations (default). A positive value applies
the move before every irot_every single-electron sweeps (VMC) or DMC steps.
Rotations are C_n rotations about the origin, irot_order=3 by default.

VMC: chooses uniformly from the nonidentity rotations (+120 or -120 degrees for
n=3). Acceptance uses the full |Psi(rotated)/Psi(current)|^2 Metropolis ratio.

DMC: each walker independently draws a group element uniformly (identity
included) and is rotated without accept/reject, so walker weights are
unchanged. This is exact only for a C_n-invariant trial wavefunction: after
each rotation psi (sign and ln|psi|) and E_L must agree with the stored values
to 1e-6 (E_L relative); otherwise the run stops with an error. The move
equalizes walker populations between symmetry-equivalent regions that
single-electron moves do not connect. Only the primary walk is rotated.

No potential, orbital coefficients, or density estimators are symmetrized.
Supported: vmc_mov1 / vmc_mov1_mpi with imetro=1, dmc_mov1 / dmc_mov1_mpi*
with idmc=2; ndim=2, ibasis=4, nloc=-8, iperiodic=0, nforce=1, and no fixed
electron (ifixe<=0). Unsupported enabled settings stop with an input error.
GLOBAL_ROTATION (VMC) and GLOBAL_ROTATION_DMC counts and maximum deviations
are local to each MPI process.
